## 核心理念

上篇文章裡我說過兩句話：

- 先搭台，再唱戲
- 先完成，再完美

這一篇，我繼續做一件更實操的事：演示怎麼把各路大佬的 SKILL，變成你自己的專屬 SKILL。

我一直覺得，最好的學習方式就是模仿。

這時候可能有人會說：這不就是「複製別人的 SKILL」嗎？

如果你已經很熟悉這套操作，那你確實不是這篇文章的目標讀者。我這篇文章就是寫給 0 基礎新手的入門演示，有些步驟會故意寫得很直白，甚至「笨一點」，因為對新手來說，真正缺的往往不是概念，而是一個看得懂、照著就能做的過程。

對從沒系統用過 AI、也沒有編程基礎的人來說，很多時候真的就差一次「明明白白、實實在在」的演示。看懂一次，路就通了。

我會用寶玉老師的 SKILL 倉庫做例子，演示如何把他的 SKILL 改造成你自己的版本。後續你還可以按自己的實際流程繼續定製。

## 第一步：先「選妃」——挑一個適合你的 SKILL

先打開寶玉老師 SKILL 倉庫的 GitHub 頁面。你如果還不熟 GitHub，也沒關係，可以先把它理解成一個「放項目文件的網盤」。

進去後會看到很多目錄名，看不懂很正常。你可以直接把瀏覽器地址發給 Codex，讓它幫你列出裡面有哪些 SKILL、分別做什麼。

## 第二步：明確需求，直接點名你要的 SKILL

比如這次我想要「Markdown 格式化」的能力，那我就直接選 baoyu-format-markdown，並告訴 Codex：

- 我想用這個 skill
- 請自動適配我的工作流
- 同時給出優化建議並執行

建議提示詞：讓 Codex 把該 SKILL 自動適應你的工作流，提出優化建議，並且執行。

## 第三步：重啟後進入「自動執行」狀態

完成改造後，重啟 Codex。之後你再按自己的寫作工作流跑流程，Codex 就會在對應步驟裡自動執行這個 SKILL。

## 最後想說：模仿不是終點，適配才是

寶玉老師的 SKILL 已經覆蓋了大多數人的需求，這點非常強。

但「強」不等於「完全適配你自己」。

所以不要生搬硬套。更實用的做法是：讓 AI 基於你的工作流提出適配建議，然後把這些建議真正嵌進你的流程裡。

這樣你得到的，不是「別人的工具箱」，而是「你自己的生產系統」。
