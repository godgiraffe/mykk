## 技巧說明

在 Claude Code 中使用 `--dangerously-skip-permissions` 參數可以跳過權限檢查，加快開發流程。

## 使用方式

```bash
claude --dangerously-skip-permissions
```

## 注意事項

此參數包含 "dangerously"（危險地）字樣，表示跳過權限檢查可能帶來安全風險，使用時需要謹慎評估。適合在可信任的開發環境中使用，以提升效率。
