CodexBar 有點重，還要瀏覽器權限。作者最初的想法是把 Amp 每日餘額用完，不需要實時監控用量。

因此開發了一個 Raycast Extension：**Agent Usage**，已發布可以在 Store 直接安裝。

## 功能特點

一鍵查看各類 AI 訂閱餘量，目前支援以下服務：

- Amp Code
- Codex
- Droid
- Gemini CLI
- Kimi
- GLM
