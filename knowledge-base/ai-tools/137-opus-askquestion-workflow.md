## 核心觀點

是的，Opus 4.6 的能力已經能達到 10 年以上經驗的程式設計師了。

## 操作經驗分享

我有個操作經驗分享給大家，你可能頭腦風暴想到一個功能，先不要急著告訴 Opus 4.6 如何做、如何完成，就算你是一個資深程式設計師😆

你可以把需求告訴它，加下面一句提示詞：

```
use askQuestionTools
```

Claude Code 會洞察你想法，詢問需求裡面不確定的地方，你回答以後生成好實現方案 review 後再實現比較穩。
